How this works

Every exercise is plain Markdown plus a tab block. New material is drafted by an agent, checked by npm run validate, and only marked reviewed once it has actually been played. Drafts stay visible on purpose: nothing is trusted until it has been through your hands.

Built with Astro and alphaTab. Practice slow, then slower.
